## 关于我

我是一名专注于**量化研究基础设施、数据 Pipelines 与 AI 驱动交易系统**的**大数据开发工程师**。

我的核心工程领域位于高吞吐数据处理、量化策略研究、AI Agent 智能体架构与自动化执行系统的交汇点。我致力于构建实用且贯穿研发与交易全生命周期的端到端量化基础设施：

`行情数据 Pipeline` ➔ `因子挖掘与特征工程` ➔ `策略研发` ➔ `策略回测` ➔ `模拟交易与审计` ➔ `自动化执行`

### 技术焦点与量化工具链

- **数据工程与基础设施**：高性能数据管道、Tick/Bar 行情数据流处理、时序数据存储与 ETL 工作流。
- **量化研究与策略评估**：多因子模型探索、A股 Alpha 选股、时序分析与 K线形态预测、系统化信号审计。
- **回测与模拟交易**：事件驱动与向量化回测引擎、模拟交易（Paper Trading）、交易成本建模与实时投资组合风控监控。
- **AI Agent 与工作流自动化**：LLM 辅助量化研究流、多 Agent 评估漏斗（结合预测模型与 Agent 循环）以及本地优先的决策支持工具。
- **交易系统基础设施**：执行网关、风险控制、交互式数据分析看板与生产级私有化部署。

我正在积极开发和维护一系列量化研究工具与生产级软件：

面向 ARC-AGI (1, 2 & 3) 基准的通用自主程序合成与 AGI 推理引擎，结合并行 MCTS 搜索、2D 网格 DSL 原语与自愈控制架。
