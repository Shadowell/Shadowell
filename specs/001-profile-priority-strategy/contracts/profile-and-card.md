## BitPro mapping operation

The existing authenticated settings contract receives alias `github-profile` and the validated
target strategy. It returns a configured Paper mapping. The operation changes no strategy or Paper
session state.

## Public response acceptance

The stable public URL returns schema version 1, `state=ok`, `mode=paper`, and current public data.
It must not contain strategy identity, instance identity, source, parameters, positions, orders, or
signals.
